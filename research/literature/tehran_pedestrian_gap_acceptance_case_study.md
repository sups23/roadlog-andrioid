# Pedestrian Gap Acceptance Behaviour — Tehran Case Study

## Citation
Search title: "Pedestrian Gap Acceptance Behavior, A Case Study: Tehran."

## Core purpose
The study models pedestrian gap acceptance in Tehran, Iran, using a binary mixed logit model and a latent variable for cautious behaviour.

## What is useful for intersection observation research
- **Latent variable approach:** Defines “caution behaviour” from observable indicators (e.g., waiting, looking both ways, accepted gap size).
- **Gender, phone use, and accompanying children:** Found to strongly affect gap acceptance.
- **Mixed logit model:** Allows for individual heterogeneity in decision-making.
- **Behavioural insight:** Distinguishes between observed actions and underlying risk attitude.

## Key takeaways for a Kathmandu project
- You can create a simple “caution score” from observable behaviours.
- Phone use and accompanying children are easy to code and highly relevant.
- Gender effects are commonly found in gap acceptance studies.

## Limitations
- Tehran traffic culture and enforcement differ from Kathmandu.
- Advanced statistical methods may be more than a small project needs.

## Suggested use
Use for inspiration on how to build a behavioural index from simple observations. Consider adding phone-use and child-presence variables to your sheet.
